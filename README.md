## ⚡ Особенности

- **Пакетная генерация видео:** Рендеринг 1080p видео локально через встроенный FFmpeg без сложных видеоредакторов.
- **Прямой аплоад на YouTube:** Автоматическая публикация и планирование видео на вашем канале.
- **Умные теги:** Автоматическое определение названия, BPM, тональности (scale/key) и соавторов из названий аудиофайлов.
- **Интеграция с Pinterest:** Подключение аккаунта Pinterest для быстрого импорта артов и обложек прямо из ленты.
- **Встроенные автообновления:** Проверка актуальной версии при старте приложения с бесшовной установкой.
